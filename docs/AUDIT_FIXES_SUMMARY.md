## Как применяются фиксы
Фиксы для `server.py` / `editor.js` / `index.html` описаны якорными патчами (`studio/*_patches.py`,
`studio/patching.py`) и **с коммита `265e49c` вшиты в сами файлы** (`python -m studio.patching` показывает
только `already`). Экспортные фиксы ставятся в загруженный модуль при старте (`studio/export_pipeline.py`).
С PR #7 `python server.py` тоже запускает защищённый `studio_server` (старый: `KICK_LEGACY_SERVER=1`).

Новые правки больших файлов идут так: патч в `studio/*_patches.py` → push в ветку `studio-fold` →
воркфлоу `fold-patches.yml` вшивает их, гоняет `tools/ci_check.sh` и кладёт отчёт в `docs/CI_REPORT.md`.

## PR #7: проверено в GitHub Actions (ubuntu, ffmpeg из apt, Python 3.12, Node 20) — 35 тестов, всё зелёное
* ✅ **Громкость одинаковая во всех путях экспорта.** `studio/loudness.py`: каждый готовый файл меряется
  (EBU R128). Если мимо цели (|I − (−14)| > 1 LU или TP > −0.5 dBTP), аудио пересчитывается вторым
  **линейным** проходом по замеру (честный two-pass) + лимитер без auto-level, видео копируется. Тишина и файлы
  без звука не трогаются. Итог в ответе клипа (`loudness`) и в `/api/studio/export-report`.
  Отключить: `STUDIO_LOUDNESS_GATE=0`. Тесты: тихий (−28 dB) и громкий (0 dB) клип → −14 ± 1.5 LUFS,
  кадры видео не тронуты (240 из 240), повторный прогон ничего не меняет, файл без звука пропущен, обёртка экспорта
  применяет гейт и к обычным экспортам без шаблона.
* ✅ **`-ss` перед `-i`** (открытый пункт аудита): проверено по коду — оба пути экспорта (`_export_layered_clip`,
  `export_clip_pack`) сикают быстро (`-ss … -t … -i`). Пункт закрыт.
* ✅ **Эффекты из шаблона ставились сломанными** (первая версия `studioAddFx` из `265e49c`): у shake было
  `fxAmp = 16*100 = 1600` и `fxPeak = 16`, `freq` терялся, время момента из **исходника** ставилось как время
  **таймлайна**, эффекты шли не на тот слой. Теперь каждый эффект создаётся тем же кодом, что хоткеи
  (`addEffectAtPlayhead`), с полями по виду эффекта, а время пересчитывается через клип, который показывает этот
  момент (`window.studioSourceToTimeline`). Если момент вне клипов — понятное сообщение, а не эффекты в пустоте.
* ✅ **Баг хоткеев, найденный по пути:** `addEffectAtPlayhead` считал клипы на первом видео-слое, а `addFxClip`
  пишет на слой эффектов. При одном клипе на таймлайне первый эффект сессии терял настройки хоткея
  (длительность, силу, звук). Теперь новый клип ищется по ссылке на том же слое, функция возвращает клип.
* ✅ **ID эффектов совпадали** при добавлении в одну миллисекунду (`"fx_" + Date.now()`) — теперь с суффиксом.
* ✅ Хоткей F писал `peak`, а остальной код читает `fxPeak` — добавлено `fxPeak`.
* ✅ **GPU-линза выдавала отладочный цвет:** в `glPasses.js` шейдер возвращал `vec4(uWaveA*1000, uK1, uCx, uCy)`
  с пометкой DEBUG, а сдвиги хроматической аберрации брались без центра линзы. Шейдер переписан один в один с
  `lens.js` (CA по неискажённому радиусу, только горизонтальный сдвиг). В `gltest.html` эталонный сэмплер был
  билинейным только по X — исправлен, отладочный вывод убран. Сам GPU-тест в CI не запускается (нужен Electron + GPU).
