# Kick Video Studio → качество уровня After Effects
## Полный план исправлений: диагноз, первопричины, целевая архитектура, пошаговое ТЗ

Репозиторий: `evgenlase044-sys/kick-video-downloader`, коммит `1b815b6` (main).
Разобраны файлы: `server.py`, `web/editor.js`, `web/index.html`, `web/style.css`, `web/app.js`, `main.js`, `engine/**` (Rust), `tv_grade.cube`, `fonts/`, `sfx/`.
Сравнивались: экспорт `Short_jesusavgn_20260926_064127_1.mp4` (1080×1920, 60fps, 5 c, ~7 Мбит/с) и референс `Bro turned into iShowSplash` (1080×1440, 60fps, 44 c).

## 0. TL;DR

1. **Текущий стек в принципе не может дать AE-качество.** Текст делается через ASS/libass (теги `\t`, `\fscx`, `\blur`), эффекты через цепочки FFmpeg-фильтров, превью — отдельный набор HTML `<video>` + CSS. Это три разных «рендерера», которые никогда не совпадут между собой и упираются в потолок libass (нет пружинной физики по словам, нет motion blur, нет нормальных масок/блендов, нет точного свечения).
2. **Rust-движок `engine/` (самый близкий к стилю референса) вообще не вызывается** из `server.py` и содержит критические баги (размер кадра декодера, FPS).
3. **Решение:** один декларативный формат сцены (`Composition JSON`) и **один GPU-рендерер (WebGL2 в Electron)**, который работает и как живое превью, и как экспорт (покадровый рендер → FFmpeg-энкодер). Что видишь в превью = то, что получишь в файле, кадр в кадр.
4. **До переписывания** есть пакет быстрых хотфиксов (1–3 дня), которые убирают самые заметные дефекты: двойной текст, «разъехавшиеся» буквы, зелёные пятна свечения, плохую раскладку кадра, превью 16:9.
5. **Отдельная первопричина «мыла»: источник 720p.** Для 9:16 из 16:9 вырезается полоса 405×720 и тянется до 1080×1920 (×2.67). Никакой цветокор это не спасёт: качать 1080p60 + нормальный апскейл.

## 1. Диагноз: что видно в экспорте

| # | Симптом | Где видно |
|---|---|---|

| D6 | **Цветокора по сути нет**: LUT 17³ + `eq contrast=1.05 sat=1.10` — косметика, картинка серо-синяя | весь ролик |

Что делает референс (и что надо уметь):
- Жирный **курсивный** гротеск КАПСОМ, небольшой кегль (~4–5% высоты), тонкая тёмная обводка + мягкая тень + лёгкое свечение цветом слова.
- **Посимвольная печать** ремарок в звёздочках (`*CRYING IN PAIN*`, `*PREPARES FOR BODY SPLASH*`) и **пословное появление** реплик с пружинным pop-ом; цвет по словам (белый/красный/жёлтый/зелёный/голубой).
- Выход текста: fade + blur/glow-out.
- **Никтеги** со стрелкой вниз, покачивание.
- **Эмодзи** (череп) со свечением, финал «blur + затемнение».
- Эффекты на ударах: **красная заливка силуэта**, **ч/б порог на 1–2 кадра**, **оранжево-белая пересветка**, **зум-панч + радиальный смаз**, **whip-переходы**, **шейк с motion blur**, спидрампы.
- Грейд: высокий контраст, сочные красные/пурпурные, продавленные тени, яркие света, резкость, виньетка, лёгкий блум.
- Кадр всегда **полноэкранный и осмысленный**: кроп на действие.

## 2. Первопричины (с привязкой к коду)

### RC1. Два независимых источника текста → D1
- `server.py` → `class ExportClipItem`: одновременно `subtitles` (рендерит `build_tv_subtitles_ass`) и `text_items` (рендерит `build_text_elements_ass`), плюс `layers`. Инварианта «ровно один источник субтитров» нет, дедупа нет.
- `web/editor.js`: `wordsToTimelineClips` + кнопка `#applySubtitlesToTimelineBtn` («На слой титров») кладут распознанные фразы клипами на дорожку «Субтитры / Текст», а параллельно стиль Shorts отправляет эти же субтитры в `subtitles`. На таймлайне два текстовых клипа («ЭТОТ /» 5.0 c и «ЭТОТ ДОНАТ СЛОМАЛ СТРИМ» 4.0 c) — два слоя.
- Жёлтая печать — ветка `if anim_in == "type"` в `build_text_elements_ass` (Dialogue на каждую букву); белая статичная фраза — ветка `build_tv_subtitles_ass`, где для `anim=="type"` или без `words` создаётся один Dialogue на `full_text`.

### RC2. Посимвольное позиционирование с чужими метриками → D2
- `_letter_positions()` → `_letter_widths()` мерят глифы через `fontTools` по файлу `_FONT_FILE_FOR[fam]`, а рисует **libass через fontconfig**, который для кириллицы может подставить другой шрифт. Метрики одного + отрисовка другим = разъезд.
- Нет глифа → `w = 0.62 * size_px`.
- `FONT_NO_CYR = {"Anton","Bebas Neue","Impact","Arial Black","Bangers"}` — неполный список, fallback только по имени.
- Каждая буква — отдельный `Dialogue` с `\pos` и своим pop-ом `\fscx112` → соседние буквы налезают, кернинг теряется.
- В цикле `for i, ch in enumerate(text)` пропускается только `\`, а `N` из `\N` рендерится как буква.
- `spacing` клиппится до 30 px и применяется к каждой букве.

### RC3. Свечение живёт отдельно от текста → D3
- В `build_tv_subtitles_ass` на слово 3 Dialogue: `Glow` слой 0 (`\blur{wide_b}\bord{core_b}`, `wide_b = max(8, size*0.14*gk)`), `Glow` слой 1, `Main` слой 2 с `\fad(15, …)`.
- Pop стартует с `\fscx68`, основной текст ещё в фейде → первые 1–2 кадра видно только размытое пятно glow. Для `text_items` хуже: `gb1 = size*0.16*(glow/60)`.

### RC4. Раскладка «верх/низ исходника» по умолчанию → D4
- UI: «Вебка: весь верх · Фон: весь низ» — при `crop_box = null`, `bg_box = null` сервер берёт половины кадра.
- Нет автоопределения вебки и выбора интересной области.
- Пикер `#pickSolo` с `object-fit: contain`: координаты нормализуются по контейнеру, а сервер (`CropBox`, «normalized 0..1 of source») трактует их как доли исходника → при леттербоксе рамка смещается.

### RC5. Качество источника и цепочка масштабирования → D5
- Скачивается 720p. 9:16 из 1280×720 = 405×720 → ×2.67.
- `_tv_grade_parts`: `hqdn3d=1.2:1.2:5:5` ПЕРЕД LUT смывает деталь, `cas=0.30` не спасает.
- Многократные `scale` (кроп → сплит → PiP → shake `crop+scale` каждый кадр) = накопление мягкости.
- Весь граф 8-бит `yuv420p`, операции в гамма-пространстве.

### RC6. Цветокор — косметика → D6
- `_tv_grade_parts`: `hqdn3d → lut3d(tv_grade.cube, 17³) → eq(contrast=1.05, saturation=1.10, brightness=0.01) → cas=0.30 → format=yuv420p`.
- Нет нормализации экспозиции/баланса белого под источник, нет кривых, split-toning, локального контраста, блума/грейна/виньетки. LUT 17³ — грубая сетка.
- `ExportClipItem.color_grade` по умолчанию `"none"`, в клиенте `"tv"`; `src_processed=True` тоже выключает грейд.

### RC7. Эффекты FFmpeg-ом → D7
- `_apply_fx_chain`: `shake` = `crop` по синусу + `scale` каждый кадр (теряет края, мылит, нет motion blur); `flash` = `blend=all_mode=addition` (клиппинг светов); `bars` = чёрные плашки. Нет зум-панча, смаза, RGB-split, масок, спидрампа.

### RC8. Превью — отдельный мир → D8
- `web/index.html`: `#studioVideoPlayer` + скрытый `#tvPreview` (`tvpTopVideo`, `tvpBottomVideo`, `tvpPipVideo`, `tvpSubs`) + отдельный `#subtitlesMonitorOverlay`.
- `editor.js`: `state.aspectRatio = "16:9"` и `state.clipper.format = "split_adhd"` — **два несвязанных состояния**. Выбор Shorts-шаблона не включает вертикальное превью; кнопка `16:9/9:16` меняет только CSS-класс `.vertical-9-16`.
- Текст в превью — `#subtitlesMonitorOverlay` (CSS `bottom:12%`), а не ASS; анимации — CSS `@keyframes` по wall-clock, не от `currentTime`.
- Грейда в превью нет (LUT только в FFmpeg).
- `activeVideoLayers()` показывает максимум 2 видеослоя, экспорт — сколько угодно.
- `setElTime` допускает рассинхрон до 120 мс; таймкод 60 fps, а шаг кадра `seekRelative(±1/30)`.

### RC9. Rust-движок заброшен и сломан
- `server.py` не вызывает `splash_engine` (`main.js` запускает только `python server.py`).
- `engine/src/ffmpeg.rs::FrameDecoder::open`: `scale=W:H:force_original_aspect_ratio=increase` без `crop` → FFmpeg отдаёт 2560×1440, а читается 1080×1440×3 байт → поток кадров едет.
- Нет нормализации FPS входа.
- `draw_emoji` копирует битмап в левый верхний угол, glow эмодзи не работает.
- `TextItem.font` игнорируется; `colors: []` → паника.
- Шаблон с абсолютными путями `C:/Users/artba/...`, канва 1080×1440 (3:4).

### RC10. Прочий техдолг
- Два определения `_sfx_maybe_file` в `server.py`.
- Пользовательский текст не экранируется для ASS (`{`, `}`, `\`).
- Дефолты расходятся: стиль `acid` / `mrbeast` / `meme`; шрифт `Anton` / `Russo One`; glow 45 / 55; грейд `tv` / `none`.
- `fonts/fonts.conf` перезаписывается при каждом старте.
- `_source_has_audio` при ошибке ffprobe возвращает `True`.
- Скачивание `-ss … -c copy` режет по ключевым кадрам.
- `fmt_ass_time` квантует до 1/60, а ASS хранит сотые — короткие слова схлопываются.

## 3. Целевая архитектура

```
┌──────────────── Electron (main.js) ────────────────┐
│  UI (editor)  ──►  Composition JSON (единый стейт)  │
│                        │                            │
│         ┌──────────────┴──────────────┐             │
│         ▼                             ▼             │
│  PREVIEW: SceneRenderer         EXPORT: SceneRenderer│
│  (WebGL2, realtime,             (тот же код, offscreen│
│   WebCodecs-декод,               покадрово, 60 fps,   │
│   от currentTime)                motion-blur сабсэмплы)│
│                                       │ RGBA кадры    │
└───────────────────────────────────────┼──────────────┘
                                        ▼
                  FFmpeg: x264/NVENC + аудио-микс (server.py)
Python server.py: скачивание, ASR (слова), автодетект вебки/лиц,
                  бит-детект, прокси-файлы, микс звука, энкод.
```

Почему так:
- **Один рендерер = WYSIWYG по определению.** Все расхождения RC8 исчезают как класс.
- **Chromium уже внутри Electron**: шейпинг текста (HarfBuzz), кернинг, кириллица, цветные эмодзи, fallback — одинаково в превью и экспорте. RC2 уходит целиком.
- **WebGL2-шейдеры** дают всё из AE-пресетов вирусных эдитов: блюры, glow, RGB-split, радиальный/направленный смаз, пороги, duotone, LUT 33³/65³, грейн, блум, маски, режимы наложения.
- **Детерминизм**: каждое свойство = функция от времени `t` (кейфреймы/пружины), никакого wall-clock CSS.
- Альтернативы: libass (потолок, RC1–3), чистый FFmpeg-граф (нет моушна, RC7), Rust CPU-движок (медленно, нет превью), Blender/MLT (тяжело), Remotion (хорош, но React-стек и лицензия для коммерции).

Библиотеки: **PixiJS v8** или свой тонкий WebGL2-слой (`twgl.js`); **mp4box.js + WebCodecs `VideoDecoder`** для покадрово-точного декода.

## 4. Фаза 0 — хотфиксы в текущем коде (1–3 дня)

**H1. Один источник субтитров (D1).**
- Где: `editor.js` (сборщик payload экспорта, ~L6000–7600), `server.py::ExportClipItem` и обработчик экспорта.
- Что: `subtitle_mode: Literal["auto","timeline","none"]`. Если на дорожке «Субтитры/Текст» есть клипы из ASR (`clip.words` не пуст) → `"timeline"`, `subtitles=[]`; иначе `"auto"` и ASR-клипы не кладутся в `text_items`. На сервере: при `timeline` игнорировать `subtitles`, при `auto` выкидывать из `text_items` элементы с `words` или совпадающие с cue (нормализованный текст + перекрытие ≥50%).

**H2. Печать без посимвольных `\pos` (D2).**
- Где: `server.py::build_text_elements_ass`, ветка `anim_in == "type"`.
- Как: **один Dialogue на строку**, скрытые буквы — `{\alpha&HFF&}` и `{\t(t_i,t_i+1,\alpha&H00&)}` перед каждой буквой. libass сам делает кернинг одним шрифтом.
- Плюс: экранировать `{}\`; не рендерить `N` из `\N`; `spacing` по умолчанию 0, максимум 6 px.

**H3. Шрифты с гарантированной кириллицей.**
- Где: `server.py` (`FONT_NO_CYR`, `CYR_FALLBACK`, `_resolve_font`), `index.html`.
- Как: при старте проверить cmap каждого шрифта на U+0410–U+044F + Ёё; в UI только прошедшие, остальным — явная пара. Добавить в `fonts/`: **Montserrat Black Italic / ExtraBold Italic**, **Inter Tight Black Italic**, **Unbounded Black**, **Manrope ExtraBold** (OFL, с кириллицей).

**H4. Свечение не раньше текста (D3).**
- Где: `build_tv_subtitles_ass`, `build_text_elements_ass`.
- Как: glow стартует с `\alpha&HFF&`, проявляется `\t(60,160,\alpha&H80&)`; убрать отдельный `\fad` у Main (или дать такой же glow); `wide_b ≤ 0.08*size`, `core_b ≤ 0.04*size`.

**H5. Осмысленная раскладка по умолчанию (D4).**
- Где: новый `POST /api/auto-regions` в `server.py`; вызов из `editor.js` при добавлении нарезки.
- Минимум: если `crop_box` не задан — `fullscreen_9_16` с кропом по центру масс лица (OpenCV YuNet, 1 кадр/сек, медиана), а не «верх/низ».
- Пикер: при переводе указателя в `{x,y,w,h}` учитывать реальный прямоугольник видео внутри `object-fit: contain`. Хранить `space: "source"`.

**H6. Цепочка грейда.**
- Где: `_tv_grade_parts`.
- Как: убрать `hqdn3d` (или `0.6:0.6:2:2` после скейла для шумных); скейл один раз `lanczos` после кропа; `cas=0.5` после апскейла; default `color_grade="tv"`.

**H7. Превью 9:16 при Shorts (частично D8).**
- Где: `editor.js` (`initTransport`, `updateTvPreview`, выбор формата/шаблона).
- Как: выбор Shorts-формата → `state.aspectRatio="9:16"`, показать `#tvPreview`, скрыть `#studioVideoPlayer` и `#subtitlesMonitorOverlay`; анимации `.tvp-letter` считать от `state.currentTime` в JS; шаг кадра `1/60`. Временная мера до Фазы 1.

**H8. Мелочи**: удалить дубль `_sfx_maybe_file`; `Field(default_factory=list)`; `_source_has_audio` → `False` при ошибке + `anullsrc`; точный трим при скачивании; **1080p60** по умолчанию.

## 5. Фаза 1 — ядро: Composition JSON + SceneRenderer (2–4 недели)

### 5.1. Формат сцены
Файл `web/core/composition.ts` + JSON Schema (валидация на клиенте и в `server.py` через pydantic).

```jsonc
{
  "version": 2,
  "canvas": { "w": 1080, "h": 1920, "fps": 60, "bg": "#000" },
  "duration": 28.4,
  "assets": { "src1": { "path": "downloads/…mp4", "w": 1920, "h": 1080, "fps": 60 } },
  "layers": [
    { "id": "bg", "type": "video", "asset": "src1",
      "time": { "in": 0, "out": 28.4, "srcIn": 2512.3, "speed": [[0,1],[4.2,0.4],[4.6,1]] },
      "crop": { "space": "source", "x": 0.05, "y": 0.1, "w": 0.32, "h": 0.8 },
      "transform": { "x": 0.5, "y": 0.5, "scale": { "k": [[0,1.0],[4.3,1.18,"spring"]] }, "rot": 0 },
      "effects": [ { "type": "grade", "preset": "viral_punch" }, { "type": "shake", "at": 4.3, "amp": 18, "dur": 0.35 } ] },
    { "id": "cam", "type": "video", "asset": "src1", "crop": { "space": "source", "x": 0.73, "y": 0.62, "w": 0.26, "h": 0.36 },
      "mask": { "shape": "roundrect", "r": 0.04 }, "transform": { "x": 0.5, "y": 0.18, "w": 0.92 } },
    { "id": "cap1", "type": "text", "style": "viral_italic",
      "text": "ЭТОТ ДОНАТ СЛОМАЛ СТРИМ",
      "words": [ { "t": "ЭТОТ", "s": 0.52, "e": 0.80 }, { "t": "ДОНАТ", "s": 0.80, "e": 1.21, "color": "#FF2A2A", "hot": true } ],
      "animators": [ { "preset": "word_pop_spring" }, { "preset": "out_blur_fade" } ],
      "transform": { "x": 0.5, "y": 0.47 } },
    { "id": "fx1", "type": "fx", "kind": "red_silhouette", "in": 4.30, "out": 4.42 }
  ],
  "audio": { "tracks": [], "sfx": [ { "at": 4.30, "file": "sfx/impact_epic.mp3", "gain": 0.9 } ] }
}
```

Принципы:
- Координаты нормализованы, **пространство указано явно** (`source` для кропов, `canvas` для позиций).
- Любое число = константа ИЛИ кейфреймы `[[t, v, easing]]`: `linear | easeOutCubic | easeOutBack | bezier(x1,y1,x2,y2) | spring(stiffness,damping,mass)`.
- Время: `timelineTime → layerLocal → sourceTime` одной функцией `mapTime(layer, t)` (включая спидрамп) — для превью, экспорта и ASR-ремапа. Убирает `subs_in_output_time` / `_remap_subtitles_for_segments`.
- Таймлайн редактора компилируется в `Composition` функцией `compileRegion(region)`. Регион «Нарезка» = одна композиция.

### 5.2. SceneRenderer (`web/core/renderer/`)
- `renderFrame(comp, t, target)` — чистая функция: свойства слоёв в момент `t` → текстуры → FBO **RGBA16F в линейном свете**, premultiplied alpha → OETF BT.709 + дизеринг → RGBA8.
- Видео: `VideoFrameProvider` на WebCodecs (`VideoDecoder` + mp4box.js) с кэшем GOP; `getFrame(asset, sourceTime)` — точный кадр.
- Прокси: сервер делает 540p-прокси с `-g 15` для скраба; экспорт — оригинал.
- Текстовые слои растеризуются один раз на уникальное состояние (кэш), анимация — трансформы/uniform-ы.

### 5.3. Экспорт через тот же рендерер
- Electron: скрытое окно/OffscreenCanvas в воркере рендерит кадры `t = n/fps`.
- **Motion blur**: N сабсэмплов на кадр (по умолчанию 8, затвор 180°) с усреднением во float-FBO. В превью — 1 сабсэмпл.
- Кадры RGBA → `VideoEncoder` (WebCodecs, H.264 High, аппаратный) ИЛИ raw в `ffmpeg -f rawvideo -pix_fmt rgba` → `libx264 -preset slow -crf 16 -tune film -pix_fmt yuv420p -colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv` (или `h264_nvenc -preset p7 -tune hq -rc vbr -cq 18 -b:v 20M`).
- Аудио микширует `server.py`, мукс `-c:v copy`. Прогресс/отмена — через существующий SSE.

### 5.4. Паритет
- `verify_all.py`: 20 эталонных композиций, кадры превью и экспорта в одинаковых `t`, **SSIM ≥ 0.99**.

## 6. Текстовый движок уровня AE

### 6.1. Растеризация
- Canvas2D `OffscreenCanvas` → текстура; **2× суперсэмплинг** + mipmap.
- Шейпинг браузерный (HarfBuzz): кернинг, кириллица, ё, цветные эмодзи.
- Раскладка: перенос по `maxWidth = 0.86*W`, баланс строк, **не больше 2 строк и 3–4 слов на экран**.
- Каждое **слово и буква — отдельный квад** со своей матрицей; позиции из общей раскладки строки (кернинг сохраняется).

### 6.2. Оформление (снизу вверх)
1. **Drop shadow**: смещение (0, 0.06em), blur 0.08em, чёрный 70%.
2. **Extrude/3D** (MrBeast): 6–12 копий по диагонали, затемнение.
3. **Outer stroke** через **SDF** (jump-flood в шейдере) — ровная обводка любой толщины (заменяет `dilate_alpha` и `\bord`). 0.06–0.14em.
4. **Glow**: двухпроходный гаусс маски (0.15em и 0.45em) цветом слова, аддитивно, интенсивность анимируется **вместе** с альфой текста.
5. **Fill**: цвет / градиент / текстура, inner shadow 1px.
6. **Sheen** (опционально).

### 6.3. Аниматоры (аналог AE Text Animators + Range Selector)

| Пресет | Поведение | По умолчанию |
|---|---|---|
| `word_pop_spring` | слово в момент `word.s`: scale 0→1 пружиной (перелёт ~118%), opacity 0→1 за 50 мс, blur 6→0 px, поворот ±3° затухающий | stiffness 420, damping 18 |
| `char_type` | буквы по одной (35–45 мс) с микро-pop 1.25→1 и вспышкой glow | 40 ms/char |
| `slam` | влёт сверху 2.2→1, motion blur, при касании шейк 6 px 80 мс | для hot-слов |
| `karaoke_fill` | фраза видна, активное слово перекрашивается + scale 1.12 | |
| `wave` / `jitter` | Perlin-дрожание 1–2 px и ±1° | rage-стили |
| `glitch_in` | 3–5 кадров RGB-split + срезы | |
| `out_blur_fade` | opacity→0, blur→12 px, scale→0.94 за 180 мс | |
| `out_burn` | пересвет glow до белого + fade | |

### 6.4. Смысловой слой
- **Hot words**: LLM/словарь выбирает 1–2 ключевых слова → цвет акцента, чуть больше кегль, `slam`.
- **Ремарки в звёздочках** (`*ОРЁТ*`, `*В ШОКЕ*`, `*ЖДИ*`): кнопка или авто по громким всплескам → `char_type`, курсив.
- **Никтеги**: текст + треугольник, **привязан к трекинг-точке лица**, bob 3 px @ 1.2 Гц.
- **Эмодзи-стикеры** 💀😭🔥 с glow и пружиной.
- Субтитры по умолчанию `y = 0.62–0.70`, оверлей safe-area Shorts/TikTok в превью.

### 6.5. Стили
Один `web/core/styles.json` — и для карточек UI, и для рендера. Новые пресеты:
- `viral_italic` — Montserrat Black Italic, белый + #FF2B2B/#FFE600, stroke 0.07em, shadow, glow 35%, `word_pop_spring`.
- `splash_remark` — `char_type`, в звёздочках.
- `mrbeast_3d` — Montserrat Black, жёлтый/белый, stroke 0.12em, extrude 10, tilt −4°.
- `hormozi_box` — плашка за активным словом с pop.
- `neon_acid` — зелёный fill, белая сердцевина, glow только после появления.

## 7. Моушн-дизайн и эффекты (шейдеры)

| Эффект | Реализация | Где в референсе |
|---|---|---|
| **Zoom punch** | scale 1→1.15 пружиной за 120 мс + радиальный смаз 3 кадра | удары, реплики |
| **Camera shake** | Perlin позиции/поворота с затуханием, с motion blur, кадр чуть увеличен | падения |
| **Whip transition** | направленный блюр 60–120 px + сдвиг, 6–8 кадров | смена планов |
| **Flash** | режим `screen`, белый/красный/оранжевый, атака 1 кадр, спад 6–10 | удары |
| **Red silhouette** | маска человека (MediaPipe/RVM, кэш) + duotone красный, 3–6 кадров | красный персонаж |
| **Threshold hit** | ч/б порог + шум, 1–2 кадра | удар об стол |
| **Overexpose burn** | exposure +2 EV + bloom + оранжевый тинт, спад 200 мс | «crying in pain» |
| **RGB split / glitch** | смещение каналов + срезы по шуму | глитч |
| **Speed ramp** | кривая `speed` (0.3× перед ударом, рывок), frame blending | прыжок |
| **Freeze frame + zoom** | стоп-кадр с зумом, «WAIT FOR IT» | ожидание |
| **Blur + darken outro** | гаусс 30 px, −1.5 EV, стикер 💀 | финал |
| **Vignette / grain / bloom** | в глобальном грейде | везде |

**Ритм**: сервер считает onsets/биты (`librosa`) + громкие пики голоса (RMS) → точки на таймлайне, эффекты «прилипают» к ним.

**SFX**: у каждого эффекта дефолтный звук из `sfx/` (whoosh на whip, impact на slam/flash, тихий click на `char_type`).

## 8. Цветокор (GPU)

### 8.1. Конвейер (float, линейный свет)
1. **Декод** YUV → RGB с правильной матрицей, TV→PC range (проверить `VideoFrame.colorSpace`).
2. **Auto-normalize на клип**: при импорте статистика (перцентили 1%/99%, баланс по серым) → авто-экспозиция и WB, параметры слоя.
3. **Primary**: exposure, temperature/tint, **lift/gamma/gain**, contrast вокруг pivot 0.18 в log.
4. **Кривые**: S-кривая, мягкий filmic roll-off светов.
5. **Цвет**: vibrance, saturation, **split-toning** (тени teal, света тёплые), HSL-вторички (усилить красные/пурпур, беречь кожу).
6. **LUT** 33³/65³, тетраэдральная интерполяция, любые `.cube`.
7. **Clarity** (unsharp большого радиуса по яркости) + **CAS после апскейла**.
8. **Bloom/Halation**.
9. **Виньетка** и **film grain** 2–4% (снимает пластиковость, маскирует бандинг).
10. **OETF + дизеринг** → 8-бит.

### 8.2. Пресеты
`Viral Punch`, `Teal & Orange`, `Night Neon`, `Clean Natural`, `Moody Film`, `B&W Contrast`, `Custom LUT`. Слайдер «Сила» 0–100%. Мгновенно в превью.

### 8.3. `tv_grade.cube`
Пересобрать в 33³ (или сгенерировать из `Viral Punch`); старый — пресет «TV Acid (legacy)».

## 9. Раскладка кадра и рефрейм

1. **Автодетект вебки** (`POST /api/auto-regions`): 1 кадр/сек, лица — OpenCV `FaceDetectorYN` (YuNet); вебка = стабильный прямоугольник вокруг лица (Canny + поиск прямоугольников, медиана); результат `cam_box` + уверенность, пользователь правит.
2. **Контент-область**: всё кроме вебки и чата; для экрана — кроп по максимальной активности.
3. **Форматы**: `cam_top_content_bottom`, `fullscreen_face`, `content_full_cam_pip`, `blur_fill`. **Запрет** дефолта «верх/низ исходника».
4. **Трекинг лица → виртуальная камера**: One-Euro-фильтр, мёртвая зона, лимит скорости; якорь для никтегов.
5. **Сегментация человека** (red silhouette, текст за человеком): RVM/MediaPipe, маски один раз при импорте, кэш `downloads/.cache/masks`.

## 10. Качество источника и финального файла

1. **1080p60 (или source) по умолчанию** в `downloader.py`/`kick_extractor.py`. Для 9:16 это 608×1080 вместо 405×720.
2. **Один ресэмплинг** в шейдере (Lanczos-3/EWA).
3. **Апскейл** (опция): FSR1 EASU + RCAS в шейдере (реалтайм); максимум — Real-ESRGAN-x2 (`realesrgan-ncnn-vulkan.exe`) для кропов < 720 px, кэш.
4. **Экспорт**: 1080×1920@60 (опционально 2160×3840 — YouTube даёт VP9/AV1 с бо́льшим битрейтом), x264 `-preset slow -crf 16` или NVENC `-cq 18 -b:v 20M -maxrate 30M`, BT.709-теги, `+faststart`, AAC 320k 48 кГц, **−14 LUFS** (двухпроходный `loudnorm`) + лимитер −1 dBTP.
5. Зерно + дизеринг вместо `hqdn3d`.

## 11. Субтитры / ASR
