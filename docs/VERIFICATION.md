## 4. Поправки, внесённые в план по итогам проверок
1. Нет «мигания композиции» — это сплит‑раскладка (V9).
2. Громкость и энкодер уже есть (V21) → нужен только **двухпроходный** loudnorm; энкодер не трогать. Мыло — от 720p и `hqdn3d`, не от энкодера.
3. `fmt_ass_time` — мелочь (V27).
4. Паритет — до кодека (V28).
5. PixiJS не рекомендуется; Remotion исключён по лицензии.
6. Пружина движка: реальные параметры ζ=0.74, ω₀≈46 (V25), а не задокументированные «stiffness 180, damping 20».
7. Groq: `segment` не запрашивается, сегменты локальные (V1) → в плане запрашивать `word`+`segment` ради метаданных фильтра галлюцинаций.
8. Трекер уже ограничен выделением, но неверно (V11) → раздельные цель/зона.
9. Автодетект/бит/LLM никогда не были в коде (V4, V5) — удаление из плана не ломает существующий функционал.

### 7.2. Шаг 0a/0b — экспорт и текст
- [ ] `/api/version` совпадает с HEAD; при подмене `server.py` Electron перезапускает бэкенд.
- [ ] Payload с ASR‑клипами в `text_items` **и** непустым `subtitles` → HTTP 422.
- [ ] Эталонный фрагмент: ровно один текстовый слой в каждом кадре (визуально + подсчёт Dialogue в ASS).
- [ ] `char_type`/печать: одна строка Dialogue на строку текста; нет буквы «N» из `\N`; кириллица + «ё» + латиница + цифры во всех шрифтах без разъезда (golden‑кадры).
- [ ] Тень смещена на `sh_off`; у тени и текста одинаковый `sway`.
- [ ] Кадры 0–12 появления слова: нет glow без текста (alpha glow ≤ alpha текста).
- [ ] Текст рисуется в `gbrp` до финального `format=yuv420p` (проверка по `-report`); на красном/жёлтом тексте нет цветной каши у обводки (сравнение кропа 4× с эталоном).

- [ ] В графе нет `hqdn3d` перед LUT; `cas` после финального скейла.

- [ ] Громкость: −14 LUFS ±1, TP ≤ −1 dBTP (двухпроходный loudnorm, `ebur128`).

### 7.3. Шаг 0c — ручные инструменты, трекинг, Groq
**Пикер**
- [ ] Видео 16:9 в контейнере 4:3 и 21:9 (леттербокс/пилларбокс): рамка, нарисованная по углам объекта, в экспорте совпадает с объектом ±1 px исходника.
- [ ] Пропорции: свободно/9:16/1:1/4:5/16:9/«как слот»; числовые поля x/y/w/h округляются в px исходника.
- [ ] Пресет канала: сохранить рамку вебки → новая нарезка того же канала → P → рамка применена без правок.
- [ ] Без рамок дефолт — `fullscreen` по центру, не «верх/низ».

**Трекинг**
- [ ] Синтетический тест: белый квадрат 60×60 px движется по синусу по чёрному фону 1920×1080@60 → ошибка центра ≤ 1 px (субпиксель), ни одного `lost`.
- [ ] Тот же тест с зоной, перекрывающей только левую половину траектории → рамка **никогда** не выходит за зону (проверка каждого ключа: `box ⊂ zone`), на правой половине — `lost=true`, позиция удерживается у края зоны.
