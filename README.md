# Kick Video Downloader & Archiver

Комплексный инструмент для скачивания записей стримов (VOD) с платформы **Kick.com** по прямым ссылкам вида:
`https://kick.com/<channel>/videos/<uuid>`

## Ключевые возможности

1. **Скачивание в любом качестве на выбор:**
   - Автоматически находит все доступные потоки качества (`1080p60`, `720p60`, `480p`, `360p`, `160p`).
   - Позволяет выбрать нужное качество перед загрузкой.
2. **Предварительный высокоточный расчет требуемого места:**
   - Парсит суб-плейлисты HLS и проводит калибровку через параллельные HTTP `HEAD` запросы к контрольным сегментам в CDN AWS IVS.
   - Вычисляет точный финальный объем видеофайла в байтах, МБ и ГБ до начала скачивания.
3. **Строгий контроль свободного места на диске:**
   - Проверяет доступное дисковое пространство на целевом накопителе (`shutil.disk_usage`).
   - Учитывает 5% буфер безопасности для процессов ремуксинга FFmpeg.
   - **Если места не хватает:**
     - Выводит предупреждение с указанием объема видео, доступного места и точного дефицита.
     - **Блокирует скачивание** и строго требует от пользователя освободить место / удалить файлы перед загрузкой.
     - Включает кнопку / команду «Проверить диск снова», позволяющую продолжить сразу после очистки.
4. **Многопоточный загрузчик и чистая сборка в MP4:**
   - Быстрая параллельная загрузка сегментов `.ts` в 12-16 потоков с автоматическими повторными попытками.
   - Сборка в один файл `.mp4` через FFmpeg (`-c copy`) без пережимания и без потери исходного качества картинки и звука.
   - Автоматическое удаление временных файлов после сборки.
5. **Два интерфейса на выбор:**
   - **Web UI** (`start_web.bat`) — веб-интерфейс в темном стиле Kick со стекломорфизмом, карточкой стрима, индикатором диска и живым прогресс-баром.
   - **CLI** (`start_cli.bat` или `python cli.py`) — интерактивный терминальный интерфейс с таблицей качеств и прогрессом.

## Способы запуска

### Способ 1: Десктопное приложение для ПК на JS / Electron (Рекомендуется)
1. Дважды кликните по файлу **`start_app.bat`** (или выполните `npm start`).
2. Запустится полноценное отдельное оконное приложение для Windows с темной темой Kick.
3. Приложение автоматически стартует фоновый сервис и подключается к нему.

### Способ 2: Запуск в браузере (Web UI)
1. Дважды кликните по файлу **`start_web.bat`**.
2. В браузере откроется страница: `http://127.0.0.1:8765`.

### Способ 3: Консольный терминальный режим (CLI)
1. Дважды кликните по **`start_cli.bat`** или выполните в консоли:
   ```cmd
   python cli.py
   ```

## Требования окружения
- **Python**: 3.10+ (протестировано на Python 3.14)
- **FFmpeg**: установлен и доступен в системном `PATH` (установлен в системе).
- **Пакеты**: устанавливаются из `requirements.txt`:
  ```cmd
  pip install -r requirements.txt
  ```
  Состав: `fastapi`, `uvicorn`, `pydantic`, `python-multipart`, `requests`, `rich`, `fontTools`, `opencv-python`, `numpy`.

## Субтитры и приватность (Groq)
Субтитры распознаются **только облачным API Groq** (`whisper-large-v3-turbo` / `whisper-large-v3`) с вашим личным ключом `GROQ_API_KEY` (`.env` или настройки; в репозитории ключ не хранится). Локальные модели распознавания не используются. Аудио отправляется в Groq **только** когда вы нажимаете «Субтитры», и только для выбранного фрагмента. Без ключа ручной текст работает как прежде.
